# Brew More

A concept site for a fictional protein iced-coffee brand. It is a motion study of a premium DTC landing page: the structure, pacing, easing and micro-interactions are documented in `ANIMATION-STUDY.md` (one level up in `../more-nutrition/`). All imagery, the 3D tub, the label and the copy are original to this demo.

Run it: `npm install`, then `npm run dev`. `npm run build` writes `dist/`. `node scripts/stage.mjs` builds for the shared demo deploy under `/more-coffee` and copies the result to `../site/more-coffee` (see the repo's `wrangler.jsonc`).

Stack: Astro 7, GSAP 3.15 (ScrollTrigger, SplitText, DrawSVG, CustomEase, Inertia), Lenis, Swiper (creative effect). The CSS minifier is set to esbuild in `astro.config.mjs` on purpose: the default (Lightning CSS) drops the `translate`/`rotate`/`scale` lines of the jelly hover.

## Where things are

- `src/pages/index.astro`: all sections, in order: loader, nav, hero, polaroids, pinned sequence, comparison table, reviews, flavour shots, payment, footer.
- `src/styles/global.css`: tokens (palette, four easing curves), fluid `em` scaling (1em = 16px at 1440px wide), every component and the phone layout.
- `src/scripts/main.js`: intro timeline, ribbon, reveals, the custom review slider, the linked Swiper pair, pointer inertia and the pinned sequence.
- `src/components/`: `Button` (the arrow-hops-across-the-pill button) and `Sketch` (hand-drawn items are two stacked copies; the second "boils").

## Images and the 3D tub

Everything in `public/img` is generated; nothing is scanned or copied.

- **Tub, hero sprite and scroll sequence** are rendered, not generated by a model. `render/jar.html` is a three.js scene (lathed tub, ribbed lid, clearcoat) with the label drawn on a canvas. `render/render.mjs` bakes the jar's path into frames with headless Chromium and `render/to-webp.py` converts them:
  - `public/img/hero/seq_1_0..22.webp`: the 23-frame idle turn of the hero tub
  - `public/img/seq/seq_0_0..199.webp`: the 200-frame scroll sequence (the tub swaps sides as each card passes, tumbles to the centre, ends as three)
  To re-render: from `render/` run `npm install`, serve the `more-coffee` folder over HTTP on port 8765, then `node render.mjs hero|seq <dir>` and `python3 to-webp.py <dir> ../public/img/hero|seq seq_1|seq_0 80`.
- **Photos and cut-outs** come from Seedream through OpenRouter: `scripts/gen.mjs jobs.json` writes to `public/img/raw/` (git-ignored) and `scripts/optimize.py` turns them into web assets. The label photo is `public/img/label/latte-photo.png`. Products are cut out by flood-filling the white backdrop from the edges, which keeps glossy highlights.

Keys: copy `.env.example` to `.env` and fill in `OPENROUTER_API_KEY`. `.env` is git-ignored. `scripts/secrets.mjs` can encrypt it to `.env.enc` with a passphrase. Each 2K image costs about 1.8 cents.

## Phones

Below 992px the page switches to a lighter version (no pinning): the cards stack and fade up, the jar canvas is dropped, and the sliders stay. The page reloads when the breakpoint, orientation or the reduced-motion preference changes so the right timelines are rebuilt. With `prefers-reduced-motion` the intro and the boil are skipped.
