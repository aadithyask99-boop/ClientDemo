# Client audits

One file per client site that is being improved: `<client>.md`. Use this template.

```
# <Client>  (<url>)  captured YYYY-MM-DD

## Brief
What the owner or client wants, the reference (if any), mode (recreate / inspiration), platform constraints.

## As-is design language
Type, colour, spacing, imagery, tone, motion, first-screen element today. Numbers from report.md.

## Keep / Fix
What works and stays. What is generic, broken or weak (checklist.md items, Impeccable findings).

## Must preserve (SEO and content)
Title, description, h1 and headings, URLs, structured data, legal text, brand assets.

## Direction
Signature idea, type, palette, first screen; sameness check result against fingerprints.md.

## Before and after
Key screenshots (small, under 300 KB each), speed and SEO numbers, Impeccable and checklist results.
```

Raw captures stay in `captures/` (git-ignored). Commit only this file and a few small key images.
