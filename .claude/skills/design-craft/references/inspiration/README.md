# Pattern cards

One short card per good idea found while researching, whether from the owner, a gallery or a live site. A card is a mechanism to borrow, not a design to copy. Fields: source and link, what it does, when to use it, how it was built or how it moves (and how we know), how to re-skin it, risks, who approved it. Add a card when the owner picks an idea, and add a line to `../patterns.md`.
