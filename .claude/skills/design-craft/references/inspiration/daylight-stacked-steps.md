# Daylight: pinned steps with an object that changes per step

- **Source:** https://godaylight.com/ (found via details.so: Stacked Scroll, Steps, Features). Studied 2026-11-03 from 12 full-resolution strips; motion not yet measured.
- **What it does:** a "how it works" sequence in three steps (Qualify, Install, Power on). Each step is a section with a small mono label ("STEP 1"), a large title, two lines of text and a button on the left, and one illustrated object on the right that changes per step: a phone card, then an isometric solar-panel drawing, then a live chart whose figure rises (1.5 to 8.2). The next step slides up over the last, so the sequence reads as one continuous scene on a warm beige ground.
- **When to use it:** a short sequence of 3 to 5 stages (process, milestones, journey) where each stage has one clear object.
- **How to re-skin:** in a restrained black-and-white reference, drop the colour and the illustration style; keep the one-object-per-stage idea with a photograph or a mark from the client, set the date or step in the reference's label style, and use the reference's easing for the swap.
- **Risks:** heavy illustration work; on phones the stack must unpin; the label above the title is an eyebrow, so use it only if the reference does.
