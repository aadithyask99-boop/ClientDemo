- **Scope:** Visual/UX, mobile, conversion and copy, technical SEO, local SEO, performance, accessibility
- **Status:** Draft
- **Branch:** `moments-and-memories`

- `journey.json`: data behind the journey map (rebuild with `_template/journey-map/build_journey.py`)
